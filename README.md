# House Price Prediction Capstone Project

This repository contains the Machine Learning capstone project for predicting house prices.

## Project Overview
- **Data Cleaning & Exploration:** Handling missing values, encoding categorical variables, and scaling features.
- **Model Development:** Training Linear Regression and tree-based models to estimate house prices.
- **Evaluation:** Evaluating model performance using RMSE and R-squared metrics.

## Project Structure
- `data/`: Contains dataset files.
- `notebooks/`: Jupyter notebooks with EDA and modeling.
- `requirements.txt`: Python package dependencies.
